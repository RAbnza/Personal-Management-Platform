# Salapiya release history

## 0.6.1+8 — 29 October 2026

**OWNER-APPROVED FULL RELEASE. Development COMPLETE.**

The owner approved the completed Windows/Android application for the owner and
three brothers with the existing limitations. The verified existing binaries are
promoted unchanged: owner-signed Android APK and unsigned Inno Setup Windows
installer, with a complete optional Windows runtime ZIP. There is no new financial,
privacy, authentication, synchronization, database, backup or UI implementation.

[Final release and project closure](FINAL_RELEASE_AND_PROJECT_CLOSURE.md) records
local paths, exact hashes, installation/update/recovery instructions, owner
acceptance, technical evidence boundaries and optional future enhancements.
Release reference: `salapiya-v0.6.1+8`. Binaries are retained locally and are not
published as GitHub release assets or distributed automatically.

The earlier [post-P6 handoff](POST_P6_RELEASE_GATE_CLOSURE_HANDOFF.md) used the same
version under its earlier BLOCKED scope. That historical result is preserved;
the final owner decision changes the approved release scope, not the test results.
